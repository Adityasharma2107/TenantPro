# TenantPro visual direction

This is the shared design direction for future TenantPro pages.

- **Architecture-led interface:** use the original apartment illustration as a low-contrast dashboard canvas and as a richer login visual.
- **Tinted glass surfaces:** avoid large blank white areas. Use soft lavender, blue, and mint gradients with readable white or near-white content surfaces.
- **Calm motion:** use short entrance transitions, soft hover lifts, and small loading states. Motion must help orientation, never slow work down.
- **Neumorphic hierarchy:** key summary cards should feel gently raised; forms should feel subtly inset. Keep borders and shadows light.
- **Clear operational color:** blue for open, violet for assigned, amber for in progress, green for resolved, and red for urgent.
- **Role-aware polish:** future tenant and technician views should keep the same system while showing only the actions relevant to that role.
